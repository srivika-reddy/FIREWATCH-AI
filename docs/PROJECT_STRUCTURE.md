## Root Files

- `app.py`: Flask application, routes, upload validation, detector orchestration, status logic, preview generation, and error handlers.
- `config.py`: Paths, model settings, thresholds, file allowlists, upload limit, demo mode, and demo location.
- `requirements.txt`: Flask, OpenCV headless, and Ultralytics dependencies.
- `README.md`: Setup, operation, API, model, testing, and limitation guide.
- `THIRD_PARTY_NOTICES.md`: Attribution, source, checksum, and licensing caveat for the fire/smoke model.
- `firewatch.db`: SQLite database created and initialized by the application.

## Backend Packages

- `database/database.py`: SQLite connection, schema initialization, insert, list, and clear operations.
- `detector/fire_detector.py`: Dedicated fire/smoke model download, checksum validation, loading, inference, class confidence aggregation, and fallback modes.
- `detector/object_detector.py`: Optional official Ultralytics YOLO model loading and supported person, animal, and vehicle counting.
- `__init__.py` files: Mark the database and detector folders as Python packages; the detector package exports both detector classes.

## Frontend

- `templates/index.html`: Server-rendered dashboard structure, status panel, monitoring preview, location card, detection cards, history table, and model/licensing notices.
- `static/js/app.js`: Image/video upload requests, camera preview controls, result rendering, alert-history loading, and history clearing.
- `static/css/style.css`: Dashboard typography, colors, cards, feed layout, status styling, responsive breakpoints, and mobile behavior.

## Runtime Data

- `models/fire_smoke_best.pt`: Verified dedicated fire/smoke YOLOv8 weights.
- `models/yolo11n.pt`: Lightweight general YOLO weights.
- `uploads/`: Uploaded source files and processed image previews. Video uploads are stored, but the video endpoint does not produce a processed video file.
- `firewatch.db`: Local alert history database.
- `.venv/` and `__pycache__/`: Local Python environment and generated bytecode directories present in the workspace; they are not application source modules.
